# 移除 Web 漏洞扫描能力，产品回到通用管理系统脚手架

产品不再承载 Web 漏洞扫描业务。我们决定**物理删除**扫描相关前后端代码、测试、配置、nuclei 模板目录与 README/compose 中的扫描依赖；启动时一次性 `DROP TABLE IF EXISTS` 清理扫描表，并删除扫描菜单/权限种子；报告所用的 **MinIO / S3 扫描桶配置一并移除**（Redis 若仍服务会话或缓存监控则保留）。领域词汇表不再包含扫描与资产术语。ADR-0002、ADR-0003 由本决策取代。未选择「仅隐藏菜单」或「保留引擎为未接线库」，是为了避免半残能力与无主基础设施继续误导后续开发。

**Status:** accepted
