# 设计系统文档：Antd-Gin Admin

> UI 模式：壳层与通用原语为 `spec-driven`（规范驱动）；Web 扫描业务模块为 `mockup-driven`（稿驱动）。扫描业务页的布局与功能专属组件以 PNG 设计稿为准；本文件只提供 Token、通用 UI 原语与实现边界，不描述具体业务页面规格。品牌色板、字体与壳层继续沿用下文「控制台对齐」规范，不为扫描模块另起品牌。

## 1. 概览与创意北极星

### 创意北极星：「控制台对齐」

本产品是通用管理系统脚手架，并在其上承载 Web 漏洞扫描业务控制台。视觉不以「另起品牌故事」为目标，而是将壳层气质对齐参考工程 `frontend/web_react_code` 的默认控制台：深侧栏、主色强调、可切换多主题（含夜间）。

产品气质是克制、高密度、可运营的后台控制台，而不是营销落地页。打破 Ant Design Pro 默认「模板蓝」的手段，不是不对称排版或装饰插画，而是：**主色与布局 Token 对齐参考控制台默认壳（原 webray，现键名 `default`）**、深浅主题成套可切换、页面样式统一走 Design Token / `createStyles`。

登录页与 `/dashboard` 不在本轮视觉改造范围内；其余壳内页面按本规范消除硬编码色，保证主题切换后对比度与选中态仍可读。

## 2. 色彩与表面架构

色板以参考工程默认控制台壳为源（实现键 `default`）：主色承担强调与选中，辅色承担顶栏/侧栏深底，第三色锚定夜间冷色文字族，中性色覆盖亮色表面与夜间底面。整体明暗基调为「深壳 + 亮内容」；夜间主题转为近黑底 + 冷色字。默认主题下主色与链接色均为 Primary `#4366B0`。

**明确指令：** 亮色内容区允许使用 Neutral `#F0F0F0` 细线做表格/卡片分隔；夜间禁止死黑粗实线堆叠，改用半透明边框 `#43434385`（幽灵描边）或背景色阶分区。禁止为「好看」叠加多条 2px+ 高对比实线框。

### 表面层级与嵌套

| 层级 | Token 意向 | 亮色 HEX | 夜间 HEX |

不适用，跳过。本轮不把毛玻璃、装饰渐变、纹理作为签名质感；层次靠色板与 Token 阴影完成。

## 3. 字体：AlibabaSans 单族阶梯

标题、正文、标签同族使用 AlibabaSans，保持 Ant Design Pro 管理台可读性；与参考工程系统栈不同，但本仓库已加载该字体，主题对齐重点在色与壳而非换字体。

### 字号阶梯（品牌板须可视化）

| 角色 | 字体族 | 用途 | 样例层级 |
|------|--------|------|---------|
| 标题 Headline | AlibabaSans | 页标题、区块标题 | 20 / 16 |
| 正文 Body | AlibabaSans | 正文、表单、导航文字 | 14 |
| 标签 Label | AlibabaSans | 辅助说明、徽章、表格次要信息 | 12 |

Fallback 栈：`AlibabaSans, -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 'Helvetica Neue', Arial, 'Noto Sans', sans-serif`。

### 信息层级

以字号与字色 Token 建立层级：标题用更深/更高对比文字色，正文用主文字色，标签用次要/三级文字色（亮色黑阶或夜间 `text-cold-*` / `text-on-dark-*`）。留白跟 Pro `pageContainer` 的 16 / 24 节奏，不靠夸张字重制造营销感。

### 字体实现约束（受限运行时须填写）

纯 Web 管理端；无小程序 / React Native / Flutter / 原生 APP。自定义字体已通过 `global.less` 中 CDN `@font-face` 加载；稿面与实现字体一致（无 PNG 稿）。

| 触点 | 稿面字体 | 实现字体 / fallback 栈 | 加载策略 |
|------|---------|----------------------|---------|
| Web 管理端 | AlibabaSans | AlibabaSans + 系统栈（见上） | CDN `@font-face`（现有 `global.less`） |
| 受限运行时 | — | — | 不适用，跳过 |

## 4. 层级与深度

层级主要通过色调叠层（深壳 / 亮内容 / 夜间底面）建立，而不是装饰线框。

*   **叠层原则：** 亮色为白卡片落在浅底上，深侧栏与内容区对比分区；夜间为 `base #050608` → 内容面 `#0F1214` / `#151921` → Modal 再抬升。
*   **环境阴影：** 卡片与浮层使用 antd `boxShadowSecondary` / `boxShadow`；避免自造多层炫光或纯黑硬阴影。
*   **幽灵描边兜底：** 必须描边时，亮色用 `#F0F0F0`，夜间用 `#43434385`；深顶栏操作悬停用叠色 Token，而非加粗描边。

## 5. 组件

以下仅定义通用 UI 原语，便于还原品牌板样张。不写页面名、业务字段布局、功能专属复合组件、领域术语或业务状态名。复用叠色必须引用 §4 Token 名。

### 按钮与交互（品牌板须可视化）

*   **主按钮：** 背景 Primary `#4366B0`，文字白；圆角跟 antd `borderRadius`；悬停/按下用 antd 主色派生阶；禁用降透明。
*   **次按钮：** antd `default`（灰/白底边框）；悬停轻微背景抬升。
*   **描边按钮：** 透明底 + Primary 边框与文字；悬停浅底可用 `primary-tint-10`。
*   **文字按钮：** 无边框，文字 Primary；悬停浅底（亮面 `colorBgTextHover` / 深面 `overlay-cold-08`）。
*   **反色按钮：** 用于深底（Secondary / 夜间 base）：文字或边框用 `text-on-dark-85` 或白；悬停背景 `overlay-cold-08`。

### 输入与表单

*   **默认：** 内容面底 + Neutral 边框；文字跟主题文字 Token。
*   **聚焦：** 边框/外发光用 Primary `#4366B0`（antd focus 环），不另造粗描边。
*   **错误：** 边框与辅助文案引用 `semantic-error`，禁止临时红色 HEX。
*   禁用降透明；夜间输入底透明/深面，边框用幽灵描边规则。

### 卡片容器

*   背景：亮色 `#FFFFFF`；夜间 `#151921`（或等价内容面 Token）。
*   圆角：antd `borderRadiusLG`（通常 8）。
*   内边距：常用 16 / 24，与 Pro `pageContainer` 节奏一致。
*   阴影：`boxShadowSecondary`；夜间可弱化阴影、改靠幽灵描边。
*   不规定卡片内业务内容排列。

### 列表行

*   默认中等密度（antd Table 默认行高）；不把全局紧凑作为默认。
*   分隔：行底分割线（亮色 `#F0F0F0` / 夜间幽灵描边）。
*   悬停：antd `colorBgTextHover` 或等价浅高亮。
*   选中：背景 `primary-tint-10`（或 antd table 选中 Token）；保持文字对比度。
*   不规定业务列字段。

### 导航

*   主形态：Pro 布局可切换 — 默认 `mix`（顶栏 + 侧栏），可选 `top`（顶部菜单）；由顶栏布局切换器写入 `localStorage`，刷新后生效；无底栏 Tab（跳过）。
*   侧栏（`mix` + default/dark）：背景 Secondary `#001529`；默认字 `text-on-dark-65`；选中背景 Primary，选中字白。
*   顶栏：与主题一致；右侧操作含布局切换 / 主题切换图标按钮，悬停 `overlay-cold-08`。

### 搜索框

*   无全局搜索，本节跳过。页面内筛选/表格搜索走「输入与表单」规范。

### 状态徽章

*   形态：antd `Tag`；字号 12；水平 padding 约 8；圆角 `borderRadiusSM`。
*   默认中性：亮色底 `#FAFAFA`、边 `#F0F0F0`；夜间底 `overlay-white-04` + 幽灵描边。
*   通用样例（错误语气，非业务状态名）：文字 `semantic-error`，背景 `overlay-error-15`。

### 图标按钮

*   热区约 32×32，图标约 16–18；默认无描边（ghost）。
*   默认色：深顶栏用 `text-on-dark-65`；亮面用正文色。
*   悬停：深顶栏 `overlay-cold-08`；亮面 `colorBgTextHover`。
*   选中：图标/字 Primary 或白（随所在面）；侧栏选中态见导航节。
*   底栏 Tab 图标选中态：不适用，跳过。

### 空状态

*   图标/插画约 64–96px；优先 antd `Empty` 默认图。
*   主说明 14px，可选次说明 12px；次要文字色。
*   可选 CTA：主按钮或文字按钮。
*   不写具体业务文案。

### Loading（若适用）

*   页面级：antd `Skeleton`（与 `src/loading.tsx` 一致）。
*   局部：antd `Spin`；表格可用组件内置 loading。
*   不另做品牌定制 spinner。

## 6. 宜忌

### 应当：

*   **应当** 颜色与交互态优先走 Design Token / `createStyles`，与主题切换同源。
*   **应当** 深顶栏/侧栏上的操作使用反色或图标按钮规范，悬停引用 `overlay-cold-08`。
*   **应当** 表单错误态只引用 `semantic-error`。
*   **应当** 空列表用空状态原语；页面切换用 Skeleton、局部用 Spin。
*   **应当** 新增样式前先查 §4 叠色表，复用已有 Token。

### 禁止：

*   **禁止** 页面内硬编码 `#1890ff` 或随意 HEX（主题切换必穿帮）。
*   **禁止** 为单页发明第二套主色或侧栏配色。
*   **禁止** 用厚重多层阴影/炫光代替 Token 阴影。
*   **禁止** 在设计规范或组件约定中写入业务状态名、页面字段布局。
*   **禁止** 本轮改登录页视觉或改 `/dashboard`。
